# Up Skill

Up skill non-tech people so that teams can make use of AI skills to improve their work experience. This skill aims to encourage you to build your network for sharing skills and your teammates' superpower.

## To the Devs

> Your skill is only useful if you can share it

## Usage in Your AI Tools (Codex, Claude Desktop, Claude Code)

- **Sender**: Use upskill to share `<skill-name>` skill
- **Receiver**: Use upskill to get `<skill-name>` from `<user-name>`

Refer to [usage.md](usage.md) for further info.

## Action files

Each action is one link - drop it into your AI tool (Claude Code, Claude Desktop, Codex) and the
tool runs it:
