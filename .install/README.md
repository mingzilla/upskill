# Install

The skill installs itself - nothing here is for day-to-day use. Each action is one link: drop it
into your AI tool (Claude Code, Claude Desktop, Codex) and the tool runs it:

| What you need                  | Action file                                                                      |
|--------------------------------|----------------------------------------------------------------------------------|
| Install on Linux / WSL / macOS | [install/action__install__linux.md](install/action__install__linux.md)           |
| Install on Windows             | [install/action__install__win.md](install/action__install__win.md)               |
| Uninstall (any OS)             | [uninstall/action__uninstall.md](uninstall/action__uninstall.md)                 |
| Check or fix an install        | [install/action__technical_diagnose.md](install/action__technical_diagnose.md)   |
